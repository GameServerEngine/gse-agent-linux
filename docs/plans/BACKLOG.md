# Planning Backlog

Record deferred Linux-agent plans here when they are useful but not active. Each backlog entry should include a short problem statement, owner repository, related repositories, activation trigger, and known stop conditions.

Do not start backlog work just because it is listed. Move it to `ACTIVE.md` when a user request or project decision makes it current.

The LGSL/GameQ/protocol-removal plan is active in this repository as a linked cross-project verification plan and is tracked in `ACTIVE.md`.
