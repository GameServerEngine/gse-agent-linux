# GSE Planning Documents

This folder contains forward-looking planning and todo documents for the GSE Linux agent and cross-project GSE work. It exists so DEV+1 can answer questions such as "what are we planning for GSE?" or "continue the LGSL removal work" by inspecting repository files instead of chat history.

Use this folder this way:

- Start with `ACTIVE.md` to see work that is currently in scope.
- Read `BACKLOG.md` for deferred plans that are not active yet.
- Follow each plan link to the detailed owner document.
- For cross-project plans, the owner repository keeps the full plan and this repository keeps local responsibilities and links.

`ACTIVE.md` is for plans with an agreed next action and stop condition. `BACKLOG.md` is for ideas or deferred work that should not be started without a fresh decision.

`docs/plans/` is planning and todo material. Completed implementation history belongs in `docs/codex-history/YYYY/`; do not use history records as the only source for future work.
